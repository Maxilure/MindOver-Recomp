# The installer's icon

`installer.ico` is the **Support** icon (a wrench) by
**[Icons8](https://icons8.com)**, in violet, downloaded from
[iconsdb.com](https://www.iconsdb.com/violet-icons/support-icon.html) as its
multi-size `.ico` (16 to 512 px).
