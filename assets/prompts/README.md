# Button prompt pictures

Everything in these folders is from **Xelu's Free Controller & Key Prompts**
by Nicolae "Xelu" Berbece (Those Awesome Guys):
<https://thoseawesomeguys.com/prompts/>

Released into the public domain under **Creative Commons 0 (CC0)**. Thank
you, Xelu! Not game data.

| Folder | Set | Used for |
|---|---|---|
| `keyboard-mouse/` | Keyboard & Mouse, Light (+ the white blank key, the circling arrow) | keys in the prompts and the Options key rows (Keyboard Icons: Light) |
| `keyboard-mouse-dark/` | Keyboard & Mouse, Dark (+ the black blank key) | the same with Keyboard Icons: Dark |
| `xbox-series/` | Xbox Series | Controller Icons: Xbox Series (and Automatic with an Xbox One / Series pad) |
| `ps5/` | PS5 | Controller Icons: PlayStation 5 (Automatic: a DualSense) |
| `ps4/` | PS4 (Xelu's "Others") | Controller Icons: PlayStation 4 (Automatic: other Sony pads) |
| `switch/` | Switch | Controller Icons: Switch (Automatic: Nintendo pads) |

Only the pictures the game's prompts need are here (one 100 x 100 PNG per
key or button, unchanged). The port draws them into the game's own prompt
pictures while the game runs (`src/input/prompt_icons.h`,
docs/findings/37).
