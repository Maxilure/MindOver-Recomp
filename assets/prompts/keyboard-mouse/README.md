# Keyboard and mouse prompt pictures

The pictures in this folder are from **Xelu's Free Controller & Key Prompts**
by Nicolae "Xelu" Berbece (Those Awesome Guys):
<https://thoseawesomeguys.com/prompts/>

They are released into the public domain under **Creative Commons 0 (CC0)**.
Thank you, Xelu!

What is here: the "Light" keyboard and mouse set (one 100 x 100 PNG per key,
unchanged), the white blank key (`Blank_White_Normal.png`, used for keys the
set has no picture of: the port writes the key's name on it) and the circling
arrow (`Directional_Arrow_Full_Circle.png`, next to the Spin key).

The port draws them into the game's own button prompts while the keyboard or
mouse is in use (`src/input/prompt_icons.h`, docs/findings/37). Not game data.
