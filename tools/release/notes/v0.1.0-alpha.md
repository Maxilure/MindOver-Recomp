**Mind over Recomp** is an unofficial, fan-made native PC port of the Xbox 360
game *Crash: Mind over Mutant*. It is not affiliated with or endorsed by
Activision or the game's other owners.

> ℹ️ **A newer version is out for Windows:** [0.2.1-alpha](https://github.com/Maxilure/MindOver-Recomp/releases/latest).
> Linux players: this is still the version for you.

> ⚠️ **Alpha:** playable, but expect bugs, crashes and rough edges. Keep a
> copy of your `user/saves` folder.
>
> **You need your own disc.** The launcher builds the game on your PC from
> an `.iso` of your own Xbox 360 disc of *Crash: Mind over Mutant* (USA).
> No game files are included.

### What's new in 0.1.0-alpha

The first public release: the whole game playable on Linux and Windows,
built from your own disc by the launcher.

### Install

1. Unpack the archive somewhere with **~25 GB free**.
2. Open **READ ME FIRST.txt** in that folder, then start **Mind over Recomp**.
3. The launcher opens on **Setup**. Install any tools it lists, pick your
   `.iso`, then press **Set up everything**. The first build takes a while.
4. Press **Play**.

| System | Download |
|---|---|
| Linux (x86-64, glibc 2.39+: Ubuntu 24.04, Fedora 40, Arch… or newer) | `MindOverRecomp-0.1.0-alpha-linux-x86_64.tar.gz` |
| Windows 10 / 11 (64-bit) | `MindOverRecomp-0.1.0-alpha-windows-x86_64.zip` |

`release.toml` is only for the launcher's update check; you don't need it.
