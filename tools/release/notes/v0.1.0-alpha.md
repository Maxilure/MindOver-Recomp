> [!WARNING]
> **Alpha.** Playable, but expect bugs and crashes. Keep a copy of your `user/saves` folder.

> [!IMPORTANT]
> **You need your own game.** An `.iso` dumped from your own Xbox 360 disc of *Crash: Mind over Mutant* (USA). These downloads contain no game files: the launcher builds the game on your computer, from your disc.

The first public release of Mind over Recomp, a native PC port of *Crash: Mind over Mutant*.

### Downloads

| System | File |
|---|---|
| Windows 10 / 11 (64-bit) | `MindOverRecomp-0.1.0-alpha-windows-x86_64.zip` |
| Linux (x86-64, glibc 2.39+: Ubuntu 24.04, Fedora 40, Arch or newer) | `MindOverRecomp-0.1.0-alpha-linux-x86_64.tar.gz` |

### How to install

1. Unpack the archive somewhere with **~25 GB free**.
2. Read **READ ME FIRST.txt**, then start **Mind over Recomp**.
3. On **Setup**, install any tools it lists, pick your `.iso` and press **Set up everything**. The first build takes a while.
4. Press **Play**.
